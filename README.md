# YMM4-LiquidGlass

Apple の Liquid Glass 風のガラスパネルを描画する [YukkuriMovieMaker4](https://manjubox.net/ymm4/) 用映像エフェクトプラグインです。  
背景をスネルの法則にもとづいて屈折させ、色収差と鏡面ハイライトを加えることで、単なる「すりガラス（ぼかし）」ではない、厚みのあるガラス板として描画します。

## インストール

1. 本リポジトリのリリースページから **`YMM4LiquidGlass.ymme`** をダウンロードします。
2. ダウンロードした **`YMM4LiquidGlass.ymme`** を実行します。
3. 画面に表示される指示に従ってインストールを進めてください。
4. インストール完了後、YMM4 を起動し、プラグインとして認識されれば導入は完了です。

## 使い方

> [!IMPORTANT]
> このエフェクトが屈折させるのは **エフェクトへの入力画像** です。  
> 単体のアイテムに掛けても、そのアイテム自身しか歪みません。

下のレイヤーをガラス越しに見せるには、**合成グループ制御**に対して掛けてください。

1. ガラスの背景にしたいアイテムをまとめてグループ化する
2. グループ制御アイテムのプロパティで **「合成」を ON** にする
3. そのグループ制御の **映像エフェクト** に `Liquid Glass` を追加する

合成を有効にしたグループ制御は、配下のアイテムを 1 枚の画像に合成してから映像エフェクトチェーンに流すため、エフェクトが背景を入力として受け取れるようになります。

## パラメータ

距離の単位は「画面の高さ = 1.0」に正規化した千分率です。解像度が変わっても見た目は変わりません。

| グループ | 項目 | 既定値 | 説明 |
| --- | --- | --- | --- |
| パネル | X / Y | 0 / 0 | パネル中心の座標（画面中央が 0） |
| パネル | 幅 / 高さ / 角丸 | 600 / 200 / 48 px | ガラス板の大きさと角の丸み |
| パネル | 角の平滑化 | 0 | 角丸をさらに滑らかにつなぐ量 |
| 屈折 | ベゼル幅 | 70 | ガラスが立ち上がる縁の帯の幅 |
| 屈折 | 厚み | 20 | ガラスの厚み |
| 屈折 | 歪み | 350 | 変位量の倍率。負の値で歪む向きが反転する |
| 屈折 | 色収差 | 100 | 縁で R/G/B の変位量をずらす量 |
| ガラス | 色 / 濃度 | 白 / 0 | この色の補色が吸収される。0 で無色透明 |
| ハイライト | 角度 | 123° | 光源の向き（0度 = 右 / 90度 = 上） |
| ハイライト | 強さ | 100 | 縁の反射の強さ |
| ハイライト | 回り込み | 50 | 光源の反対側の縁に回り込む光の割合 |
| 影 | 強さ / 広がり / Yオフセット | 0 / 18px / 6px | パネルの外側に落とす影 |
| すりガラス | 有効 | オフ | 内側を曇らせる。縁の屈折は鮮明なまま残る |
| すりガラス | ぼかし量 / 開始 / 遷移 | 30 / 0 / 50 | 曇りの強さと、曇り始める位置・遷移幅 |

## 仕組み

1. 角丸矩形の符号付き距離場から、輪郭からの距離 `x`（0 = 輪郭 / 1 = ベゼル内端）を求める
2. 高さ関数 `h = 1 - sqrt(1 - (1-x)²)` でガラスの断面を作る
3. 変位量 `h × dh/d(dist) × 厚み × 歪み × 勾配の正規化` を求める
   輪郭でも内側でも 0 になり、ベゼルの中間が最大になる
4. 距離場の勾配の逆向き（＝外向き）へ変位させて背景をサンプリングする。R/G/B で変位量を変えると色収差になる
5. ベール・ランベルトの法則 `exp(-吸収係数 × 光路長)` でガラスの色を乗せる
   光路長はガラスの厚みに比例するので、縁ほど色が浅くなる
6. Schlick のフレネル近似でスペキュラーハイライトを乗せる
   最外周は切り立った壁なので視線がかすめて反射率が 1 に近づき、輪郭に沿った細い線になる

すりガラスを一様に掛けると縁の屈折と色収差が潰れてしまうため、距離場で混ぜ具合を変え、傾斜のある縁は鮮明なまま平らな内側だけを曇らせています。

## ビルド

```
dotnet build -c Release
```

YMM4 本体の DLL は `libs/` に同梱しています。環境変数 `YMM4_PATH` に YMM4 のインストールフォルダを設定しておくと、そちらの DLL を参照し、ビルド後に `%YMM4_PATH%\user\plugin\YMM4LiquidGlass\` へ自動配置します。
